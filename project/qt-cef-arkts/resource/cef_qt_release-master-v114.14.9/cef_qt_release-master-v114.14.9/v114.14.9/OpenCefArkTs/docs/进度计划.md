### 链路验证数据流

```
方向 A: CEF HTML → ArkTS 原生页面
  window.ClientAPI.navigateToNative('OneKeyLogin', cb)
  → MyCefV8Handler → SendProcessMessage
  → TCSimpleHandler → navigate_callback_
  → EWAdapterC::navigate_bridge_ → DefaultNavigateBridge
  → uv_queue_work → napi_call_function
  → NavigationBind.ets → router.pushUrl()

方向 B: ArkTS → CEF 加载 URL
  adapter_c.cefLoadUrl('html/profile.html')
  → CefLoadUrl (NAPI) → load_url_bridge_
  → CefBridge::LoadURL() (纯 CEF) / MainWindow::LoadURL() (Qt)
  → TCSimpleHandler::LoadURL()
  → CefBrowser::GetMainFrame()->LoadURL()
```

### 已确认的用户视角流程 — OpenCefArkTs

```
启动 App
  → MyAbilityStage.onCreate()
    → adapter_c.initFunc() + adapter_c.cefInit()
  → EntryAbility → loadContent('pages/Index')
  → Index.ets 显示全屏白色 XComponent (SURFACE)
    → XComponent.onLoad → adapter_c.cefSurfaceReady()
    → CefBridge::OnSurfaceReady() → CreateBrowser()
    → CEF 创建浏览器，默认加载 about:blank (default_url_ 为空)
  → 用户看到空白页面 (CEF 浏览器 about:blank)
```

> ⚠️ 当前纯 CEF 版启动后 CEF 加载的是 `about:blank`（`default_url_` 为空），home.html/login.html 等 H5 页面不自动加载。
