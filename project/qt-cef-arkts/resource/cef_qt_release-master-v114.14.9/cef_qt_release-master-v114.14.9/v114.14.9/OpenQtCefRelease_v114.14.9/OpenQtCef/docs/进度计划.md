### 链路验证数据流

```
方向 A: CEF HTML → ArkTS 原生页面
  window.ClientAPI.navigateToNative('OneKeyLogin', cb)
  → MyCefV8Handler → SendProcessMessage
  → TCSimpleHandler → navigate_callback_
  → EWAdapterC::navigate_bridge_ → DefaultNavigateBridge
  → uv_queue_work → napi_call_function
  → NavigationBind.ets → router.pushUrl()

方向 B: ArkTS → CEF 加载 URL
  adapter_c.cefLoadUrl('html/profile.html')
  → CefLoadUrl (NAPI) → load_url_bridge_
  → MainWindow::LoadURL() → TCSimpleHandler::LoadURL()
  → CefBrowser::GetMainFrame()->LoadURL()
```
